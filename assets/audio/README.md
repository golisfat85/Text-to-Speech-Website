Put voice samples here as MP3s. The file names are set in `assets/js/config.js`:

- Home page samples (`samples`): `eleanor.mp3`, `marcus.mp3`, `british-female.mp3`
- Voice pack samples (`packs`): `packs/storytellers.mp3`, `packs/bedtime.mp3`, ...

Make them with Cadence itself: 10–20 seconds each, one or two sentences that
show off the voice. Until a file is here, its card shows "Sample coming soon".
